# FICHE DE TÂCHE : V5-T02 — RECHERCHE MULTICRITÈRE SIMPLIFIÉE & PAGINATION

**ID Tâche :** `V5-T02`  
**Version :** V5  
**Priorité :** P1  
**Cycle de rotation :** Rotation C  
**Statut :** ⏳ **Planifié**

---

## 1. OBJECTIF
Ajouter le support de la pagination `Pageable` et des filtres simples (par ville et par type de bien) côté backend Spring Boot, et intégrer la recherche dynamique sur les écrans dédiés de Flutter et React Native.

---

## 2. ASSIGNATIONS TRIPARTITES DÉTAILLÉES

### Membre 1 — Application React Native (Rotation C)
- **Objectif :** Développer l'écran de recherche dans `react-native/darlink_react_native/src/features/properties/screens/SearchScreen.tsx` avec barre de recherche, sélecteur de ville (Tunis, Sousse, Djerba) et déclenchement des requêtes avec query parameters (`?city=...&type=...`).
- **Fichiers :** Écran et composants de recherche React Native.
- **Tests :** `npx tsc --noEmit`.

### Membre 2 — Backend Spring Boot (Rotation C)
- **Objectif :** Implémenter `PropertySpecification.java` (Spring Data JPA Specifications) pour construire les requêtes dynamiques selon les paramètres optionnels, et adapter le contrôleur pour gérer la pagination `Pageable` (`page`, `size`, `sort`).
- **Fichiers :** `backend/darlink-backend/src/main/java/com/darlink/repository/PropertySpecification.java`, `PropertyController.java`.
- **Tests :** Tests MockMvc vérifiant le filtrage par ville et par type.

### Membre 3 — Application Flutter (Rotation C)
- **Objectif :** Développer l'écran de recherche dans `flutter/services_immobilier_flutter/lib/features/properties/screens/search_screen.dart` avec barre de recherche (`SearchBar`), puces de filtre (`FilterChip` pour le type et la ville) et appel API paginé.
- **Fichiers :** Écran et widgets de recherche Flutter.
- **Tests :** `flutter analyze`.

---

## 3. CRITÈRES DE VALIDATION (DoD)
- [ ] Une recherche par ville (ex: `Djerba`) filtre instantanément la liste sur Flutter et React Native.
- [ ] La pagination fonctionne correctement (chargement de la page suivante sans doublon).
